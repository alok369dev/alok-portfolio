# Alok | Portfolio

Personal portfolio website. A single static page: `index.html` (HTML, CSS and JavaScript in one file).

## Edit your projects
Open `index.html`, find the `projects` list near the bottom, and fill in the
`built` line and `url` for each project.

## Before going live
- Replace `https://[YOUR-DOMAIN]/` in the `<link rel="canonical">` tag with your real domain.
- Add screenshots, results and testimonials when you have real ones.

## Deploy
1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New > Project, import the repository, and deploy.
   No build settings are needed (Framework Preset: Other).
